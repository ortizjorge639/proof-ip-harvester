# Connectors

Proof & IP Harvester is connector-agnostic. The workflow contract stays the same across harnesses; connector implementations change.

Required connector categories:

| Category | Examples |
| --- | --- |
| Work reasoning | WorkIQ, Microsoft 365 Copilot, Graph-backed semantic search |
| Messages | Teams chats, Teams channels |
| Email | Outlook / Exchange |
| Calendar | Outlook calendar and meetings |
| Files | OneDrive, SharePoint |
| Destination store | Markdown vault, SharePoint library, Git repo, Loop workspace |
| Notification | Teams, email, Slack, dashboard |

Use the connector notes in this folder to map the workflow onto a specific harness.
