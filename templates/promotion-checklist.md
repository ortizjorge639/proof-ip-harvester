# Promotion Checklist

Use this checklist before moving a candidate out of the candidate inbox.

## Validation

- [ ] The candidate has a clear CP, RI, or combined lane.
- [ ] The evidence level is accurate.
- [ ] Source pointers are present.
- [ ] Private details are not included in outbound-ready wording.
- [ ] The reusable value is clear to someone outside the original context.
- [ ] The target folder is appropriate.

## Promotion target

Choose one:

- [ ] `responses/`
- [ ] `wiki/concepts/`
- [ ] `wiki/architectures/`
- [ ] `wiki/outputs/`
- [ ] Keep in raw for more evidence
- [ ] Other approved destination: `{{destination}}`

## Approval

- [ ] Approved by reviewer.
- [ ] Promotion path confirmed.
- [ ] Any sharing copy reviewed.
